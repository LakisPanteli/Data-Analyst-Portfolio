# Bike Rental Analysis
## Introduction
<p>In this project I will be trying to find the Machine Learning method that best predicts the count of total rental bikes (‘cnt’) each day over a two-year period. That means I will be measuring the test error rates of each method and the one with the least test error will be the one that most accurately predicts ‘cnt’. I shall use the test mean squared error (MSE) to measure how close the predicted response value for a given observation is to the true response value for that observation. The smaller the value of the test MSE, the closer the predicted responses are to the true response value.</p>
<p>The methods I will be using are multiple linear regression, best subset selection, forward and backward stepwise selection, Ridge regression, the Lasso, Principal Components Regression (PCR), Partial Least Squares (PLS), Generalised Additive Models (GAM), Regression Trees, Bagging, Random Forests and Boosting.</p>

## <p> Data and exploratory analysis </p>
<p>The data source I will be using to test these Machine Learning methods is the Bike Sharing Dataset, using the prediction of bike rental count daily (‘cnt’) based on environmental and seasonal settings. There are 731 observations and 16 variables. When analysing this data and applying the machine learning methods I shall not be using the variables ‘instant’, ‘dteday’, ‘registered’ and ‘casual’. This is because they add no value when analysing the data on ‘cnt’ because ‘instant’ is simply just the number of the observation and ‘registered’ and ‘casual’ add up to the value of ‘cnt’ so there is no need to keep them in. The variable ‘dteday’ will not be used because there are variables such as ‘yr’, ‘mnth’, ‘season’, ‘weekday’, ‘workingday’ and ‘holiday’ which cover for the specific day and in fact make the model easier to interpret as they are giving you a more general value of date and time. The variable ‘cnt’ is most correlated with ‘temp’, ‘atemp’, ‘season’, ‘yr’ and ‘weathersit’. I then created some boxplots, scatterplots and histograms to analyse what the data is showing.</p>

## <p>Machine Learning models </p>
<p>After exploring the data and analysing it, I began running the different machine learning methods to see which method best predicted ‘cnt’.</p>

**<p> Multiple Linear Regression** </p>
<p>Firstly, I used multiple linear regression. I split the data into training and test data. Seen as there are only 731 observations in this data set, I set the training data to a random sample equal to half of these observations and the test data is the remaining 50% of data. Looking at the summary of this regression, it is clear that the model is overall significant as it has a large F-statistic of 159 (which is a lot higher than 1), which means we can reject the null hypothesis (that there is no relationship between the dependent variable and independent variables) and accept the alternative hypothesis that there is a relationship between the dependent variable (‘cnt’) and at least one of the independent variables. The residual standard error (RSE) is 815.5. The RSE is an estimate of the standard deviation of the error term. It is the average amount that the response will deviate from the true regression line. This means the actual value of ‘cnt’ deviates from the true regression line by approximately 815.5 or 18.1%, on average.</p>
<p>The test MSE can be used to measure how well the predictions of the model match the observed data, where it shows how close the predicted response value is to the true response value for that given observation. The test MSE of this linear regression is 931,117.8. At face value this seems very large, as this appears to tell us that the actual response is not very close to the predicted response a lot of the time. This suggests that the model may not fit the relatively inflexible least squared method used in multiple linear regression and that a more flexible model would fit this model better.</p>

**<p> Best Subset Selection** </p>
<p>Next, I used the best subset selection method. This method also uses least squares, however with less variables. It involves finding a subset of the predictors, p, that are seemingly related to the response variable (‘cnt’) and using least squares on this. I used the same set of variables as used for multiple linear regression. After running this method, I analysed the R-squared value for the given number of variables in the model. When only one variable is used the R-squared is 0.398 or 39.8%. R-squared is a measure of fit, explaining the proportion of variability in Y that can be explained using X. Numbers closing to 1 means the regression has explained a lot of the variability in the response. In the one variable model only ‘atemp’ is used to explain the response variable ‘cnt’, so this means ‘atemp’ explains approximately 39.8% of the variability in ‘cnt’. Adding more variables will always increase R-squared, however in this model the R-squared with 6 variables are included is 0.791, which is a significant increase from the 1 variable model, showing the variability in ‘cnt’ is being predicted more. However, when all variables in this model are included R-squared only increases to 0.800, showing when adding these last 6 variables they do not add too much in explaining the variability.</p>
<p>Due to the fact the R-squared is guaranteed to increase when adding variables, which means if we use it to select the best model it will always be that with all variables, one can use different ways to choose the best model. I have used Cp, BIC and adjusted R-squared to select the best model. When using Cp the best model still uses all the variables. This is the same for adjusted R-squared too. However, when using BIC, the best predicted model uses only 8 variables. With this I found which variables these 8 were and ran multiple linear regression including only these variables. The test MSE of this regression is 889,847.6. This is lower than the test MSE when running multiple linear regression with all the variables, showing the best subset method has improved the model slightly.</p>

**<p> Forward Stepwise Selection** </p>
<p>Forward stepwise selection uses a smaller set of models than best subset selection, beginning with a model with no predictors and adding one at a time. Backward stepwise selection is another method I used that, compared to forward stepwise selection, begins with all predictors and removes one at a time. Like the best subset selection method, Cp and adjusted R-squared computed that all variables were used in the best model for both forward and backward stepwise selection. Also, like best subset, when using BIC, 8 variables are used in the best model. The test MSE of both forward and backward stepwise selection using these 8 variables is 889,847.6, which is the same as that of best subset selection. This value is lower than that of multiple linear regression, showing an improvement in the model, however the MSE still seems relatively high for a prediction model.</p>

**<p> Ridge Regression and the Lasso** </p>
<p>Next, I used the shrinkage methods Ridge regression and the Lasso, that shrink the coefficient estimates towards zero. Firstly, I used Ridge Regression. After tuning the model to find the best value of lambda, which is 0.97701, the test MSE using this value of lambda is 912,452.9. To find the best value of lambda I used the grid function with values ranging from 10^5 to 10^-3, to cover the whole range of instances including the null model with the intercept only to the least squares fit. To find the best value cross-validation is used, whereby lambda is chosen where cross-validation is smallest. This method performed a bit better than the multiple linear regression, however not by much (MSE of 912,452.9 compared to 931,117.8). The advantage the ridge has over least squares is to do with the bias-variance trade-off. If lambda = 0, the Ridge regression would give the least squares estimates, and the variance would be very high. However, as lambda increase variances decreases, with the negative being an increase in bias. I also used the one-standard-error rule, whereby the selected model is the one where MSE is within 1 standard error of the lowest point of the curve. Therefore, this chooses the most simple model, the one with the least predictors. The test MSE with this is 928,168.6, which is a bit higher than the model when the best value of lambda is used, so it is still best to use the previous model, especially due to the fact there is not many variables anyway, so this simplified model is not really gaining too much. However, Ridge regression performed worse than the subset, forward stepwise and backward stepwise selection models, hence is not the most preferred method thus far.</p>

<p>The Lasso is another shrinkage method. Similarly, to the Ridge regression it shrinks the coefficients towards zero, however will make some of them exactly zero if lambda is significantly big. There are 2 variables that have been set to 0 in this model, which are ‘mnth’ and ‘temp’. After tuning the model to find the best value of lambda, which is 15.9, the test MSE using this value of lambda is 886,331.2. To find the best value of lambda I used the same grid that was used for the Ridge, as this covers the full range of scenarios. This is the smallest test MSE value so far, out of all the methods, and has performed better than the ridge regression. The reason for this could be due to the fact that there are not many predictors with large coefficients, hence the lasso which uses less predictors performs better in terms of variance and bias, and hence MSE. Likewise, with Ridge regression I applied the one-standard-error rule to find the most sparse lasso model. The test MSE of this model is 915,469.5, which is larger than the model using best lambda value, and only adds one more zero coefficient variable. Therefore, the original lasso model preforms better. It also performed slightly better than the forward and backward stepwise selection methods, and hence is the best method used so far.</p>

**<p> Ridge Regression and the Lasso** </p>
<p>Principal Components Regression (PCR) is the next method I used. This is a dimension reduction method, whereby the predictors are transformed, using principal components, and using these a least squares model is implemented. Fundamentally, fitting a least squares model on these predictors should give better results, as overfitting risk will be reduced, whilst still be able to predict most of the variability in the response variable. The smallest cross-validation (CV) error is when 7 components are used and the percentage of variance explained in the predictors is 89.31% and the percentage of variance explained in the response (‘cnt’) is 82.63%. The test MSE of the PCR when using 7 components is 939,310.3, which is the largest test MSE of the models I have used so far. Therefore, this method is not preferred to use for this model.</p>

**<p> Ridge Regression and the Lasso** </p>
<p>Partial Least Squares (PLS) is another dimension reduction method, which creates new features and uses least squares on these new features. The smallest CV error is when 8 components are used and 84.92% of the variance of the predictors explained and 83.01% of the response (‘cnt’) explained. The percentage explained of ‘cnt’ is higher in this model than the PCR because PLS also finds the directions that explain the response, as well as the predictors, whereas PCR only attempts to do the latter. The test MSE for when 8 components are used is 879,996.5, which is lower than the test MSE of the all the methods used so far, however not by a significant amount, suggesting methods used later on may be better. It does, however, show how the multiple linear regression can be improved by using less variables that still explain a lot of variability. </p>

**<p> General Additive Models (GAMs)** </p>
<p>All the models so far have used a linear model whereby the least squares method has been used but improved in several ways. However, there are strong assumptions in doing this and if the problem we are looking at doesn’t fit a liner model well then this could explain the seemingly high test MSE values. Relaxing the linearity assumption could help with the prediction problem. General Additive Models (GAMs) can be used for this, whereby the linear components are replaced with non-linear functions. I fit the GAM with smoothing splines, which is done by back-fitting. I found the top 3 predictor variables to use in this model by using the best 3 coefficients chosen by the forward stepwise selection, which I found to be ‘season’, ‘yr’ and ‘atemp’. I then used cross-validation to find the best degrees of freedom for the regression splines. I found that the best degrees of freedom for ‘season’ is 4 and for ‘atemp’ it’s 9. As ‘yr’ is qualitative I left it as it is and it’s converted into 2 dummy variables. The test MSE value for this GAM model is 884,527.6 which is better than linear regression, Ridge regression and PCR. It is comparable to forward and backward stepwise selection and Lasso, performing slightly better than both. However, it performs a little bit worse than PLS. The p value for ‘atemp’ suggests there is significant evidence that a non-linear term is required for this variable, however the large p value for ‘season’ suggest that this term needs a linear function. The R-squared value of this model is 0.759 which shows the predictor variables explain quite a lot of the variability in Y (the closer R-squared is to 1 the more variability in the response has been explained) and hence I can conclude the model includes the most important variables.</p>

**<p> Bagging** </p>
<p>Bagging is the next model used which improves the decision tree method, which has high variance. Bagging constructs ‘B’ regression trees using ‘B’ bootstrapped training set, and the average of these ‘B’ trees reduces the variance, which should improve the prediction accuracy. The test MSE of using bagging is 536,017.7. This is a significant improvement on any method used so far, which indicates the model is more non-linear and also this model sacrifices interpretability of the model for the improvement in prediction in accuracy, hence this is understandable why this method works so much better. The variable ‘yr’ appears to be the most important variable due to the percentage decrease in accuracy if it was removed from the model would be 195.5%, as well as having a high decrease in node impurity averaged over all the trees of 418206143. ## <p> Conclusion </p>
<p>In this project I have, firstly, set out the problem I tried to answer, which was to work out which machine learning method best predicts the count of total rental bikes (‘cnt’) each day over a two year basis. I did this by measuring the test MSE of each method and the one with the lowest predicts the response variable ‘cnt’ the best.</p> 

<p>Next, I explored the data, removing any variables that were not necessary in this problem. I found the number of variables and observations in the data set, finding which variables seemed most important. I then created some graphs, including box plots, scatterplots and histograms and explained what was being shown in these graphs.</p>

<p>After exploring the data, I started running the machine learning methods. The methods I used were multiple linear regression, best subset selection, forward and backward stepwise selection, Ridge regression, the Lasso, PCR, PLS, GAM, Regression Tree, Bagging, Random Forests and Boosting. After comparing all the test MSEs of the methods the Random Forests method with mtry = 5 works the best with a test MSE of 517,961.7, with bagging the most comparable with 536,017.7. The worst performing model was PCR with a test MSE of 939,310.3 and multiple linear regression with a test MSE of 931,117.8. This shows the more flexible methods perform better than those that are less flexible but more interpretable. This is also why Ridge, Lasso and subset selection, including forward and backward stepwise selection, have not performed particularly well, as especially the Lasso is even more restrictive than linear regression. PLS and GAM performed slightly better than linear regression, subset selection, Ridge, Lasso and PCR, however not by much. GAM is more flexible than linear regression so that could be a reason it performed better. As the variable ‘atemp’ was significantly shown to fit a non-linear term this would increase the accuracy of the prediction, however for the variable ‘season’ showed a linear term was suitable. It could be due to the lesser number of variables used in this method that it doesn’t perform dramatically better than those other methods. GAMs are also restricted to be additive. Tree-based methods were used next, whereby after pruning the regression tree the test MSE found was the best so far (806,763.7). This could be due to the fact it is more flexible than linear regression, subset selection and Lasso. However, regression trees best property is its ease to interpret more than anything, hence isn’t best at prediction. Bagging, Random Forests and Boosting provide the most flexible models used in this problem I am addressing so it is no surprise the least test MSE was found when using these. Random Forests with 5 variables being used (mtry=5) provided the least test MSE with 517,961.7. Bagging and boosting also perform very well compared to all the methods used before, however not as well as Random Forests. This could be due to the fact Random Forests decorrelates the trees, whereas bagging doesn’t, which does not reduce the variance substantially. The most flexible methods used have performed the best which are Bagging, Random Forests and boosting. Therefore, I can conclude that my model is more non-linear and hence a flexible method, in this case bagging and Random Forests, is best used to predict to response variable ‘cnt’.</p>
